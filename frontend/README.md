# Frontend do Casona54

Interface em React + TypeScript usando Vite. Para iniciar a aplicação localmente, siga a seção **Rodar localmente** no [README principal](../README.md).

O endereço da API é configurado pela variável `VITE_API_URL`. Para desenvolvimento local, copie `.env.example` para `.env`; o valor padrão aponta para `http://localhost:8080`.
